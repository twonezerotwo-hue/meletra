# medical-lecture-transcriber - main environment (Python 3.11, Windows 11, NVIDIA RTX 2070)
#
# Verified together on: Windows 11, Python 3.11.9, NVIDIA driver 617.14, RTX 2070 (sm_75).
# Why these pins (details in README "Dependency decisions"):
#   * torch 2.14.1+cu126  - the cu126 wheel BUNDLES cuBLAS 12 and cuDNN 9, the two libraries that
#                           CTranslate2 4.x needs on Windows but does not ship. The plain PyPI torch
#                           wheel for Windows is CPU-only and would silently break the GPU path.
#   * ctranslate2 4.8.2   - CUDA 12 + cuDNN 9 build, supports Turing (sm_75) float16 / int8_float16.
#   * faster-whisper 1.2.1 - requires ctranslate2 >=4,<5; provides Silero VAD, hotwords, word timestamps.
#   * transformers 5.19.0 - backend for third-party Whisper fine-tunes (Turkish medical model).
# The driver reports CUDA 13.4, which is fine: drivers are backward compatible with the CUDA 12 runtime.
